A structured Case Studies plugin with ACF integration, related case studies logic, and reusable shortcodes.

== Description ==

Case Studies is a lightweight WordPress plugin designed to manage and display **Case Study** content in a structured, reusable way.

It integrates seamlessly with **Advanced Custom Fields (ACF)** and provides:

- A custom template structure for Case Studies
- Relationship-based related case studies with fallback logic
- Reusable shortcodes for listing and displaying related case studies
- Featured case study handling
- Clean separation of logic, templates, and helpers

The plugin is built following WordPress coding standards and is safe to use across pages, posts, and custom post types.

== Features ==

* Custom Case Study templates
* ACF-powered structured fields
* Relationship field with automatic fallback
* Prevents selecting the current post as related
* Ensures a fixed number of related posts
* Shortcode support for frontend rendering
* Featured case study support
* Clean uninstall handling

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the **Plugins** menu in WordPress
3. Ensure **Advanced Custom Fields (ACF)** is installed and active
4. Assign the provided ACF field groups to the desired post types
